# Tiny Wins release handoff

The app is built and tested. Complete these account-specific items before uploading:

- [ ] Add your Apple Account to Xcode.
- [ ] Confirm an active Apple Developer Program membership.
- [ ] Replace `com.example.TinyWins` with a unique bundle identifier you control.
- [ ] Select your development team under Signing & Capabilities.
- [ ] Confirm that “Tiny Wins” is available as an App Store name.
- [ ] Publish `PrivacyPolicy.md` and a support/contact page, then add their public URLs to App Store Connect.
- [ ] Create the app record in App Store Connect using bundle version `1.0` and build `1`.
- [ ] Complete the age-rating questionnaire; the app contains no objectionable content.
- [ ] Complete App Privacy as “Data Not Collected.”
- [ ] Complete export compliance. The app contains no custom encryption or networking.
- [ ] Make a signed Archive build, validate it, and upload it through Xcode Organizer.
- [ ] Upload the screenshots in `Screenshots/` and paste the copy from `Metadata.md`.
- [ ] Test the processed build through TestFlight before submitting for App Review.

Suggested review notes: “Tiny Wins is an offline accomplishment journal. No login is required. Tap the + button to add an entry; History displays saved entries. All content remains on device.”
